## Hippocampal neuron and astrocyte responses to noradrenaline and natural aorusal
This repository will contain analysis scripts for the preprint [Duss et al. (2026)](https://www.biorxiv.org/content/10.64898/2026.01.16.699885v1).

Two-photon datasets are deposited in a Zenodo repository. They include preprocessed datasets (total of 20 GB) with extracted neuronal and behavioral variables, as well as results of analyses and metadata.

Further analysis scripts will be published in this repository before publication in a peer-reviewed journal.
